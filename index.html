RUMBO

Algorithms with JS Vanilla

Proyecto enfocado en la práctica y comprensión de la lógica de programación mediante diferentes ejercicios realizados con JavaScript. Incluye el uso de HTML5 y CSS3 para la estructura y presentación visual, mostrando soluciones a problemas comunes a través de código claro y funcional.

Dynamic Vehicles

Sitio web interactivo que simula una tienda de vehículos, permitiendo a los usuarios explorar diferentes modelos, ver detalles y realizar compras. El proyecto utiliza HTML5 para la estructura del contenido, CSS3 para el diseño visual y JavaScript para la interactividad, como la selección de productos y la actualización dinámica del carrito de compras.

Animal Foundation

Landing page para fundación de animales, diseñada con un enfoque limpio y amigable que resalta las actividades y servicios de la organización, mostrando información sobre adopciones, cuidado animal y campañas de concienciación. Se utilizó HTML5 para estructurar el contenido de manera clara y semántica, y CSS3 para aplicar estilos modernos y una paleta de colores armoniosa, ofreciendo una experiencia de navegación agradable y visualmente atractiva.

Algorithms with JS

Repositorio de algoritmos en JavaScript, diseñado para mostrar y practicar diversas soluciones a problemas clásicos de programación. Este proyecto incluye implementaciones de algoritmos como ordenamiento, búsqueda y estructuras de datos, proporcionando una base sólida para mejorar habilidades de codificación. Se utilizó JavaScript para la lógica de programación, HTML para la estructura básica de presentación y CSS para aplicar estilos sencillos y mejorar la legibilidad del código. El enfoque principal es educativo, permitiendo a los usuarios explorar y entender la implementación de algoritmos fundamentales.

DRIVEWAYS

FITNESS

Algorithms with Vanilla JavaScript Intermediate/Advanced Level

Landing page para practicar y mostrar algoritmos de nivel intermedio y avanzado en JavaScript, diseñada con un enfoque educativo que permite implementar soluciones eficientes a problemas complejos como búsqueda, ordenamiento y manipulación de datos. Se utilizó HTML5 para estructurar el contenido de manera clara, CSS3 para aplicar estilos básicos y JavaScript para la lógica de programación, ofreciendo una experiencia de aprendizaje práctica y comprensible.

Se utilizó HTML5 para estructurar el contenido de manera semántica, CSS3 para aplicar estilos básicos y JavaScript para implementar la lógica de cálculo y la interacción con el usuario, ofreciendo una experiencia práctica y educativa.
